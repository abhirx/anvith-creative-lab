# Anvith Creative Labs

Official website prototype for Anvith Creative Labs.

## Preview

GitHub Pages URL (once enabled): https://abhirx.github.io/anvith-creative-lab/

## Development

This initial version is a standalone, dependency-free website in `index.html` (HTML, CSS, JavaScript). Edit and commit it to the `main` branch to update the site. GitHub Pages should use **Deploy from a branch → main → /(root)**.

## Content status

- Collective reach is a placeholder awaiting verified data.
- Brand names are illustrative campaign associations, including agency-led engagements; validate rights and wording before public launch.
- Contact email, final logos, and additional brand names are not yet configured.

## Design direction

CreativeFuel-inspired: warm ivory, dark typography, golden highlights, circular motion, spacious editorial layout. All content and artwork should be original to ACL.
